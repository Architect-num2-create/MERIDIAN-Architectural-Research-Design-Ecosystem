# FORK EVALUATION

A fork is doing this right if:

- It has its own Contradiction Map with at least as much honesty as this one's, not a copy of it.
- It can point to one Canon item it earned the hard way — through a real Decision, not an assertion.
- A hostile reader, applying this project's own Red Team standard to the fork, finds something the fork already knew about.

A fork is doing this wrong if:

- It keeps the four historical sources but drops the constraint discipline — using "transformation" as a synonym for "aesthetic remix."
- It treats the Dark Forest layer as decoration instead of a working organ with its own registers.
- It cites MERIDIAN's conclusions without citing MERIDIAN's method — taking the seven ziggurat domes and skipping the reasoning that produced them.
