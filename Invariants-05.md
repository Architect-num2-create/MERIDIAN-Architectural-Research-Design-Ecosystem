# MERIDIAN — Invariants

An invariant is not something that sounds important.

It is something the architecture can change around without losing its identity.

For now I would keep these few.

### The project must transform, not reproduce

If a historical reference becomes directly recognizable as the source of a piece of the building, that is a warning.

The source can be visible.

The copied object should not be.

### The building needs an internal order

Multiplicity cannot become a pile of interesting objects.

There has to be a relationship between centre, parts, axis, void, height and movement.

The exact order can change.

The need for order cannot.

### Difference has to remain connected

The parts can differ in geometry, height, pattern or character.

They still have to belong to one building.

The unity should come from relationships, not from making everything identical.

### Void has to matter

A courtyard, cut, opening or gap should change the architecture.

If removing it would make almost no difference, it was probably only composition.

### Form has to survive without ornament

Strip the colour away.

Strip the pattern away.

Strip the historical costume away.

There should still be an architecture left.

That architecture may later accept ornament, colour and cultural language, but it cannot depend on them for existence.

### The centre has to earn its position

The central condition is not protected because "the project has a centre".

It stays only if it does something:

organizes movement,

creates spatial hierarchy,

changes structure,

controls light,

creates gathering,

or produces another real architectural consequence.

### Transformation must produce consequence

Changing a form is not enough.

Every serious transformation should eventually alter something spatial, structural, environmental, material or experiential.

Otherwise it is just a drawing operation.

---

These are provisional.

If later evidence shows that one of them is false, it should be removed.

An invariant is not a belief to defend.

It is a condition the architecture has earned.
