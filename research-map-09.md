# 09 — RESEARCH MAP

## Purpose

A map, here, is not a metaphor — it is the connective layer that shows how a
single question travels through the dossier: which sources answer it, which
evidence grades support it, which operator it produces, and which design
decision it eventually feeds. The [Question System](../03_QUESTION_SYSTEM/)
says what to ask. The [Four-Source Matrix](../05_FOUR_SOURCE_MATRIX/) says
what the sources offer. This file is where the two are traced against each
other.

A rendered visual version of this map belongs here once the underlying
connections are stable enough to draw without redrawing weekly. Until then,
the map exists in table form, which is more honest about what is actually
established.

## How to extend this map

A new trace is added the moment a question moves from "asked" to "at least
partially answered" — not when it is fully resolved. An incomplete trace
with an honest "not yet argued" is more useful here than a complete-looking
trace that quietly skips a step.
