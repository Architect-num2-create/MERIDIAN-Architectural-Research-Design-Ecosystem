# PROVENANCE

Every RES-### in this project has to answer one question honestly: what SRC-### did this come from, and how many steps of interpretation sit between them?

The chain is always: SRC → EVD → CLM → INT → DEC → TRF → EXP → RES. Skipping a link doesn't make a claim more confident — it makes it unverifiable. RES-001 (the cruciform plan carrying seven domes) has all eight links filled in; that's why it's Canon and most of the rest of the project isn't yet.

A claim with no visible chain back to a Source isn't wrong by default — but it's not Canon-eligible until the chain exists, no matter how long it's been treated as true in conversation. "We've been saying this for months" is not provenance.

Forks inherit MERIDIAN's chain up to the point they diverge. After that, they build their own — they don't get to borrow this project's provenance for claims this project never made.
