# FORK TAXONOMY

- **Type A — Method Fork.** Same transformation method, entirely different sources. The most valuable kind — it actually tests whether the method survives outside its birth case.
- **Type B — Extension Fork.** Same four sources (Peter, Basil, Ilkhanid, Achaemenid), pushed further or differently. Useful, but still living inside this project's specific find.
- **Type C — Critical Fork.** Built specifically to attack MERIDIAN's own Contradiction Map and Canon. Should be welcomed harder than any other type, not defended against.
- **Type D — Pedagogical Fork.** A studio, a class, a professor using this as a teaching structure. Carries different obligations than the other three.
