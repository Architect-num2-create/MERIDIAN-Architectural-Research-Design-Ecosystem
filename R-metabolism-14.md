# Protocols for Staying Alive Rather Than Becoming an Archive

- Every time Dossier III (the paper) changes a claim, this dossier's Contradiction Map (Organ II) gets checked against it in the same sitting — a claim that changes without the map noticing is how a living system quietly starts lying to itself.
- New red-team entries get added by whoever is hardest on the project that week, including, honestly, by whoever is writing this file. Self-red-teaming counts, as long as it's dated and never quietly rewritten later.
- Nothing in the Failure Atlas or Dark Branches (Organ III) gets deleted, only appended to — a scar that's erased stops being useful as anatomy.
- Before Layer 5 opens to real forks, Organs II and III get a second pass specifically hunting for anything a hostile first-time reader would find in under five minutes. If the project's own dossier can't find it first, a stranger will.
- Every new organ or file added to this dossier must be able to point to at least one earlier organ it disagrees with, contradicts, or complicates — an organ that only agrees with the rest of the body isn't a nervous system, it's decoration.
