**v0.2 — Research Development (not started).** Triggers when Dossier I's Source, Evidence, and Claim registers actually hold real entries instead of `[Source]` placeholders.

None yet carry real epistemic tags or real IDs — the actual blocker to calling this version complete.

**v0.5 — Core Foundation (in progress, this pass).** Constitution, Ontology, Knowledge Graph schema, Canon, Rejected/Unresolved/Experimental registers, and the fork architecture being laid down under `core/`.

**v1.0 — First Major Release.** Not reachable until every register in every Dossier has moved from placeholder to real entry, and every claim in Dark Forest carries an epistemic tag.

**Rule going forward:** a version number moves only when something real changed — not when a file was added. A folder full of well-written placeholders is still v0.1.
