# 25 — REPRESENTATION

Representation is the last translation.

It should reveal the architecture that already exists, not manufacture one that does not.

---

## Different drawings should reveal different truths.

### Plan

Shows how the building holds together horizontally.

Centre.
Field.
Void.
Movement.
Threshold.
Rhythm.

### Section

Shows what the plan hides.

Height.
Depth.
Weight.
Light.
Structure.
The real character of the dome.

### Diagram

Shows transformation.

Not every step.

Only the steps that actually explain why the architecture became what it became.

### Model

Shows relationships that drawings can flatten.

Mass.
Void.
Thickness.
Shadow.
Scale.

### Image

Should make us feel the space.

Not make us believe the architecture is better than it is.

---

## The existing presentation already contains an important clue.

The transformation sequences are not decoration around the project.

They show that the project wants to be understood through **becoming**:

mass → split → aggregation → cross

and

layer → opening → radial curvature → sectional exposure.

The final representation should preserve that idea of becoming.

But the physical building must remain the destination.

The process cannot become more important than the architecture it produced.

---

## Representation should also expose contradictions.

If the plan is strong but the section is weak, show the section.

If the exterior is impressive but the interior is unresolved, do not hide it with images.

A serious architectural presentation has enough confidence to show where the real work is.

---

## The final set

At minimum, the representation should allow someone to understand:

where the building is,
how it is entered,
how it is organized,
where the centre is,
how the masses relate,
how the section changes,
how light enters,
how it stands,
and what was transformed.

Everything else is secondary.

---

## One final test

Put the drawings on the wall.

Remove every title.

Remove every paragraph.

Remove the historical names.

Look at the project as if you have never heard its explanation.

If the drawings still contain a recognizable architectural argument,

then the representation is doing its job.

If not,

make the architecture stronger before making the graphics louder.
