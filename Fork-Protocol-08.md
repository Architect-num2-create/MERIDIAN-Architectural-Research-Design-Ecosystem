# FORK PROTOCOL

1. Read the Constitution first. Not the README — the Constitution. If Articles I through VII don't make sense, the method won't either.
2. Keep one source of your own choosing completely whole, the way Peter's plan stayed whole here. Name which one, and why, before touching anything else.
3. Write your own Contradiction Map before writing your own Design dossier. If you can't find at least three real tensions in your own project within the first week, you haven't looked hard enough yet.
4. Tag every claim with an epistemic status (F1–R1) from day one. Retrofitting tags later is exactly the mistake this project made and had to go back and fix.
5. Cite MERIDIAN properly — see CITATION.cff at the repo root.
6. A fork owes nothing back to this repository except the method's honesty with itself. No permission is needed to diverge completely from the four historical sources used here.
