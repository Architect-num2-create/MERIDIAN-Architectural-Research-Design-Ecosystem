# CONTRIBUTION

You don't need permission to fork. You need permission to say you speak for MERIDIAN — those are different things, and this file is about the second one.

If you're adding to *this* repository directly, not a fork:
- Every Source you add gets an SRC-### the same day, even if you haven't finished evaluating it yet. Half-registered beats unregistered.
- Every Claim you add gets an epistemic tag before it gets merged. No tag, no merge — this isn't bureaucracy, it's the one rule that kept Dark Forest from being usable for three passes.
- If you disagree with an existing Canon item, you don't edit it. You write a REJ-### explaining what you tried instead, and open an Amendment discussion on the Constitution. Canon bends through argument, not through pull requests.
- Pedagogical use (Type D forks — a class, a studio) doesn't need to contribute anything back. But if a student finds a real Contradiction or Blind Spot MERIDIAN missed, that's worth a message to the author before the semester ends, while it's still fresh.

What gets you removed as a contributor: quietly resolving a Contradiction in the text instead of the Contradiction Map, or citing a Source that was never actually looked at.
