# ARCHIVE INTEGRITY

The Archive is only worth trusting if it can't be quietly rewritten. Here's what guarantees that, for now: every superseding event is a dated git commit, in a public repository, with the old version still readable in that repository's history — not a private note taken at someone's word.

That's a thin guarantee, honestly. It depends entirely on the git history staying public and unaltered. Strengthening it — timestamped hashes, an external mirror, something harder to argue with — belongs in Experimental, not Canon, until it's actually built.
