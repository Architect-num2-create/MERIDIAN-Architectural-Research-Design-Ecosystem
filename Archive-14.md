# ARCHIVE

Nothing that ever reached Canon, Rejected, or Experimental status gets deleted from this project. It gets moved here when it's superseded, never erased.

What lives in the Archive right now: nothing yet — every Canon item is still its first version, every Rejection is still active. The Archive's first real entry will be whatever Canon item survives its first Amendment; until then, this file is a promise more than a record.

Rule: an Archive entry keeps its original ID forever, even after superseding. RES-001 v1 stays RES-001 v1 in the Archive even if a future RES-001 v2 replaces it in Canon. Renumbering history is the one thing this project will not do to itself.
