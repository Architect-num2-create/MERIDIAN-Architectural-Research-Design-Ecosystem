# MERIDIAN CONSTITUTION

I don't reproduce history. I decode it, break it into logic, and let the pieces fight until something new is left standing. That's not a research method I follow — it's the one rule everything else here bends around.

**Article I — The Plan Stays Whole.**
Saint Peter's cruciform footprint doesn't get touched. Every other source can be broken, mutated, recombined — the plan is the one constraint kept on purpose, so the freedom everywhere else means something.

**Article II — No Top Belongs to a God.**
Seven domes, none of them carry a cross, a lantern, a spire, or an onion. Not decoration removed for simplicity — the actual thesis. Every source got overruled here equally.

**Article III — Numbers Mean Before They Measure.**
7 domes, 5 columns, 185 columns — chosen for what they say, not for what a load calculation would say. Nobody, including future me, gets to quietly rewrite this into "structural derivation" language. If the Skeleton work ever shows a number lands in a safe structural range, that's a coincidence worth noting, not a justification to retcon the intent.

**Article IV — Unfinished Is Not the Same As Failed.**
The sheet that started this got turned in unfinished and scored 20/20. That fact stays load-bearing in how this project thinks about itself. "Finished" was never the highest value here — "true" was.

**Article V — Forked, Not Frozen.**
This isn't a monument. The Core exists so somebody who never meets me can take the method and run it on four sources I never touched. When that happens, they inherit the method, not my four buildings.

**Article VI — Say the Contradiction Out Loud.**
Every real tension in this project — symbolic vs. structural, open vs. protected, mystery vs. rigor — gets written down where a stranger can find it. A project that hides its own doubts from itself is the only kind of failure worth being embarrassed about.

**Article VII — A Human Signs This.**
AI helps this project think faster and build more precisely. It doesn't decide what's true here. Every claim, every design call, everything that becomes Canon — a human being stands behind it with his name on it.

**Amendment rule.** This constitution changes the way everything else here changes — openly, with the old version kept in the Archive, never quietly overwritten.
